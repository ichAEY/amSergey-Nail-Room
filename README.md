# Nail Room — TANEM Salon

Production website for the Nail Room salon, 18 Sayat-Nova Avenue, Yerevan, Armenia.

- Salon engine: `ichAEY/Shablon-only-for-salons`, approved revision `33e20e61e2d4382a98518e2d7ac275a4a3d22b8a`.
- Live client content: `site-data.js`; primary source: `business.json` (business type corrected to salon).
- The former master engine and its code/assets have been removed.
- Live photos: `hero.webp`, `profile.webp`, and `gallery-01.webp` through `gallery-25.webp`.
- Remaining original photos are stored under `source-photos/` and excluded from the public site.
- GitHub Actions validates and publishes on pushes to `main`.

Unverified working hours and individual staff identities are not invented.
